# Login and account help

## Common login issues

Customers may have trouble signing in because of:

- Incorrect email address
- Incorrect password
- Expired session
- Locked account after repeated failures

## Password reset

If the customer forgot the password, direct them to the password reset flow and
ask them to use the email address tied to the account.

## Account verification

If the customer cannot access the email inbox needed for reset, escalate to
support for identity verification.

## Security reminder

Never ask the customer to disclose a password or one-time verification code in
chat or by email.
