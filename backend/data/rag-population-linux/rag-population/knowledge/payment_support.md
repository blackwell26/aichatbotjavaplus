# Payment support

## Accepted payments

The store accepts major credit cards and supported digital wallets.

## When payment is authorized

Payment authorization occurs when the order is placed. The final charge is
captured when items are prepared for shipment.

## Common decline reasons

A declined payment may result from:

- Incorrect billing address
- Expired card
- Insufficient funds
- Bank security controls

Customers should verify their details and contact their bank before trying
again.

## Agent safety rules

Customer-service agents must never request or record:

- Full card number
- Card security code
- Account password
- One-time verification code

## Split shipments

When an order contains multiple shipments, charges may appear separately.
The total of all captured charges will not exceed the confirmed order total
unless the customer later approves an order change.
